# こんな時はどうする

koyomi が表示するエラーと警告を、メッセージ ID ごとにまとめています。メッセージの先頭にある ID（例: KOYOMI-E2101）で検索してください。
「…」の部分には、接続先の名前などの具体的な内容が入ります。

## 接続・認証（21xx）

### KOYOMI-E2101 接続先のエンジンに接続できないとき

- 種類: エラー
- メッセージ: 接続先 … に接続できません。（…）
- 原因: 接続先のエンジンが停止している、HTTP を受け付ける設定になっていない、またはファイアウォールで通信が遮断されている可能性があります。
- 対処: 接続先のエンジンが起動していること、[http] の lan = true、ファイアウォールの設定を確認してください。

### KOYOMI-E2102 要求が届いたかどうかを確認できないとき

- 種類: エラー
- メッセージ: 要求が接続先に届いたかどうかを確認できません。（…）
- 原因: 要求の送信後に通信が切断された、または応答の内容を確認できなかったため、接続先で処理された可能性があります。
- 対処: 履歴を確認し、必要な場合は再度実行してください。

### KOYOMI-E2103 接続先の証明書が登録された fingerprint と一致しないとき

- 種類: エラー
- メッセージ: 接続先 … の証明書が登録された fingerprint と一致しません。（接続先が示した値: …）
- 原因: 接続先の証明書が入れ替えられた、または別の PC に接続している可能性があります。
- 対処: 接続先で koyomi http fingerprint を実行して値を比較し、一致する場合は koyomi.toml の fingerprint を書き換えてください。

### KOYOMI-E2104 接続先からの応答がタイムアウトしたとき

- 種類: エラー
- メッセージ: 接続先 … からの応答がタイムアウトしました。
- 原因: 通信が遅い、または接続先のエンジンが混み合っている可能性があります。
- 対処: 通信の状態と接続先の負荷を確認し、再度実行してください。

### KOYOMI-E2105 接続先のトークンのシークレットが保存されていないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンを保存したシークレット … が存在しません。
- 原因: 資格情報ストアに、接続先の [[remote]] の token が指すシークレットが保存されていません。
- 対処: koyomi secret set … を実行し、接続先の [http] のトークンを保存してください。

### KOYOMI-E2106 接続先のトークンのシークレットを資格情報ストアから読み込めないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンのシークレット … を読み込めません。（…）
- 原因: 資格情報ストアにアクセスできない、またはストアがシークレットの読み込みを拒否した可能性があります。
- 対処: 資格情報ストアの状態を確認し、koyomi secret set … でトークンを保存し直してください。

### KOYOMI-E2107 接続先がトークンを受け付けないとき

- 種類: エラー
- メッセージ: 接続先 … がトークンを受け付けません。
- 原因: 保存されたトークンが、接続先の [http] に登録されたトークンと一致しない可能性があります。
- 対処: 接続先の [http] のトークンを確認し、koyomi secret set … で保存し直してください。

### KOYOMI-E2108 画面とエンジンの通信形式のバージョンが一致しないとき

- 種類: エラー
- メッセージ: 画面とエンジンのバージョンが一致しません。（画面 …、エンジン …）
- 原因: 画面が送った通信形式の番号が、接続先のエンジンのものと異なります。
- 対処: 画面とエンジンの koyomi を同じバージョンに更新してください。

### KOYOMI-E2109 接続先の応答を読み込めないとき

- 種類: エラー
- メッセージ: 接続先 … の応答を読み込めません。（…）
- 原因: 応答が想定した形式ではありません。接続先の koyomi とバージョンが異なる、または通信が途中で途切れた可能性があります。
- 対処: 接続先の koyomi のバージョンを確認し、再度実行してください。

### KOYOMI-E2110 接続先のエンジンが画面からの操作に対応していないとき

- 種類: エラー
- メッセージ: 接続先 … のエンジンは、この画面からの操作に対応していません。
- 原因: 接続先のエンジンに /door が存在しません。古いバージョンのエンジンである可能性があります。
- 対処: 接続先の koyomi を新しいバージョンに更新してください。

### KOYOMI-E2111 接続先との TLS 接続に失敗したとき

- 種類: エラー
- メッセージ: 接続先 … との TLS 接続に失敗しました。（…）
- 原因: 接続先の証明書または TLS の設定に問題がある可能性があります。
- 対処: 接続先のエンジンの [http] の設定と、接続先のアドレスを確認してください。

### KOYOMI-E2112 接続先のアドレスを読み込めないとき

- 種類: エラー
- メッセージ: 接続先のアドレスを読み込めません。（…）
- 原因: アドレスが https://ホスト[:ポート] の形式ではありません。
- 対処: アドレスを https://ホスト[:ポート] の形式で指定してください。

### KOYOMI-E2113 接続先が想定外の応答を返したとき

- 種類: エラー
- メッセージ: 接続先 … が想定外の応答を返しました。（…）
- 原因: 接続先のエンジンが、エラーまたは想定外の状態を示す応答を返しました。
- 対処: 接続先のエンジンの状態とログを確認してください。

### KOYOMI-E2114 接続先のトークンでは画面を操作できないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンでは、画面を操作できません。
- 原因: トークンの利用者のロールが edit 未満である、または nets か roles で絞り込まれています。
- 対処: edit 以上のロールを持ち、nets と roles で絞り込まれていない利用者のトークンを使用してください。

### KOYOMI-E2115 koyomi.toml に接続先が1件も登録されていないとき

- 種類: エラー
- メッセージ: 接続先 … は、koyomi.toml に [[remote]] が存在しないため使用できません。
- 原因: koyomi.toml に [[remote]] が1件も書かれていません。
- 対処: koyomi.toml に name、url、fingerprint、token を持つ [[remote]] を追加してください。

### KOYOMI-E2116 指定した接続先が登録されていないとき

- 種類: エラー
- メッセージ: 接続先 … は koyomi.toml の [[remote]] に存在しません。（登録済み: …）
- 原因: 指定した名前の [[remote]] が koyomi.toml にありません。
- 対処: 登録済みの接続先の名前を指定するか、[[remote]] を追加してください。

### KOYOMI-E2117 接続先を切り替えている最中に要求を送ろうとしたとき

- 種類: エラー
- メッセージ: 接続先を切り替えている最中のため、要求を送信していません。
- 原因: 画面が接続先を切り替えている間は、要求を送信しない設計になっています。
- 対処: 切り替えが終わってから、再度実行してください。

### KOYOMI-E2120 接続先のトークンを資格情報ストアに保存できないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンを資格情報ストアに保存できません。（…）
- 原因: 資格情報ストアにアクセスできない、またはストアが書き込みを拒否した可能性があります。
- 対処: 資格情報ストアの状態を確認し、再度実行してください。

### KOYOMI-E2121 接続先の登録を koyomi.toml に書き込めないとき

- 種類: エラー
- メッセージ: 接続先 … を koyomi.toml に書き込めません。（…）
- 原因: koyomi.toml への書き込み権限がない、またはディスクの状態に問題がある可能性があります。保存したトークンは資格情報ストアから削除済みです。
- 対処: koyomi.toml の場所と書き込み権限を確認し、再度実行してください。

### KOYOMI-E2122 接続先の登録を koyomi.toml に書き込めず、保存したトークンも削除できないとき

- 種類: エラー
- メッセージ: 接続先 … を koyomi.toml に書き込めません。（…）資格情報ストアのトークンも削除できませんでした。（…）
- 原因: koyomi.toml への書き込みに失敗し、その後の資格情報ストアからのトークンの削除にも失敗しました。
- 対処: koyomi.toml の書き込み権限を確認し、不要なトークンは koyomi secret delete で削除してください。

### KOYOMI-E2123 接続中の接続先を変更しようとしたとき

- 種類: エラー
- メッセージ: 接続先 … は接続中のため、変更できません。
- 原因: 画面が現在この接続先に接続しています。
- 対処: 別の接続先に切り替えてから、再度実行してください。

### KOYOMI-E2130 接続先の名前が入力されていないとき

- 種類: エラー
- メッセージ: 接続先の名前が入力されていません。
- 原因: 名前の欄が空です。
- 対処: 接続先の名前を入力してください。

### KOYOMI-E2131 同じ名前の接続先がすでにあるとき

- 種類: エラー
- メッセージ: 接続先 … はすでに存在します。
- 原因: 指定した名前の接続先が、koyomi.toml の [[remote]] にすでに登録されています。
- 対処: 別の名前を指定してください。

### KOYOMI-E2132 接続先の名前に使えない文字があるとき

- 種類: エラー
- メッセージ: 接続先の名前 … は使用できません。
- 原因: 名前に空白、制御文字、または / \ " ' : が含まれています。
- 対処: 空白と / \ " ' : を含まない名前を指定してください。

### KOYOMI-E2133 接続先の URL が正しくないとき

- 種類: エラー
- メッセージ: 接続先の URL が正しくありません。
- 原因: URL が https:// で始まっていない、または空白が含まれています。
- 対処: https:// で始まり、空白を含まない URL を指定してください。

### KOYOMI-E2134 接続先のトークンが入力されていないとき

- 種類: エラー
- メッセージ: 接続先のトークンが入力されていません。
- 原因: トークンの欄が空です。
- 対処: 接続先で発行したトークンを入力してください。

### KOYOMI-E2135 接続先のトークンのシークレットをほかの接続先が使用しているとき

- 種類: エラー
- メッセージ: シークレット … は、ほかの接続先が使用しています。
- 原因: 登録しようとした接続先と同じシークレットの名前を、別の [[remote]] が使用しています。
- 対処: 別の名前を指定してください。

### KOYOMI-E2136 接続先のトークンのシークレットがすでに存在するとき

- 種類: エラー
- メッセージ: シークレット … はすでに存在します。
- 原因: 資格情報ストアに同じ名前のシークレットがあり、上書きしない仕様になっています。
- 対処: koyomi secret delete … でシークレットを削除するか、別の名前を指定してください。

### KOYOMI-E2137 変更しようとした接続先が koyomi.toml に存在しないとき

- 種類: エラー
- メッセージ: 接続先 … は koyomi.toml に存在しません。
- 原因: 操作の途中で、ほかの場所から koyomi.toml が変更された可能性があります。
- 対処: 接続先の一覧を開き直して、再度実行してください。

### KOYOMI-E2138 変更しようとした接続先が [standby] または [primary] で指定されているとき

- 種類: エラー
- メッセージ: 接続先 … は … で指定されているため、変更できません。
- 原因: koyomi.toml の [standby] の watch または [primary] の standby が、この接続先を指しています。
- 対処: 先に koyomi.toml の … を別の接続先に変更してください。

### KOYOMI-E2139 接続先の変更後に koyomi.toml の内容が意図と一致しないとき

- 種類: エラー
- メッセージ: koyomi.toml の [[remote]] を書き換えられませんでした。
- 原因: 書き換えた内容を読み込み直したところ、意図した内容と一致しませんでした。
- 対処: koyomi.toml の内容を確認し、再度実行してください。

### KOYOMI-E2150 SSH の接続先に接続できないとき

- 種類: エラー
- メッセージ: 接続先 … に SSH で接続できません。（…）
- 原因: 接続先で sshd が起動していない、ポートが閉じている、またはホストのアドレスを解決できない可能性があります。
- 対処: 接続先のホスト名とポート、sshd が起動していること、ファイアウォールの設定を確認してください。

### KOYOMI-E2151 SSH の接続先がユーザー名、パスワード、または鍵を拒否したとき

- 種類: エラー
- メッセージ: 接続先 … がユーザー名、パスワード、または鍵を受け付けません。
- 原因: SSH の認証が接続先に拒否されました。
- 対処: ジョブの on のユーザー名と、password または key の設定を確認してください。

### KOYOMI-E2152 SSH の接続先のホスト鍵が登録された値と一致しないとき

- 種類: エラー
- メッセージ: 接続先 … のホスト鍵が host_key と一致しません。（登録した値: …、接続先が示した値: …）
- 原因: 接続先のホスト鍵が変更された、または別の PC に接続している可能性があります。
- 対処: koyomi sftp hostkey で接続先のホスト鍵を確認し、正しい場合は host_key を書き換えてください。

### KOYOMI-E2153 接続先との接続が途中で切れたとき

- 種類: エラー
- メッセージ: 接続先 … との接続が途中で切れました。（…）
- 原因: 通信の途中で接続先が接続を閉じた、またはネットワークが途切れた可能性があります。
- 対処: 接続先とネットワークの状態を確認し、再度実行してください。

### KOYOMI-E2154 SSH または WinRM の接続先からの応答がタイムアウトしたとき

- 種類: エラー
- メッセージ: 接続先 … からの応答がタイムアウトしました。
- 原因: 接続先に届かない、または接続先の応答が遅い可能性があります。
- 対処: ホスト名とポート、ネットワークの状態、接続先のリスナーとファイアウォールを確認してください。

### KOYOMI-E2160 WinRM の接続先に接続できないとき

- 種類: エラー
- メッセージ: 接続先 … に WinRM で接続できません。（…）
- 原因: 接続先の WinRM の HTTPS のリスナーが起動していない、ファイアウォールでポートが遮断されている、またはホストのアドレスを解決できない可能性があります。
- 対処: 接続先の WinRM の HTTPS のリスナーと、ファイアウォールの WinRM のポート（既定は 5986）を確認してください。

### KOYOMI-E2161 WinRM の接続先が Basic 認証のユーザー名またはパスワードを拒否したとき

- 種類: エラー
- メッセージ: 接続先 … がユーザー名またはパスワードを受け付けません。（Basic 認証）
- 原因: ユーザー名かパスワードが正しくない、または接続先で Basic 認証が有効になっていない可能性があります。Basic 認証で接続できるのは、接続先のローカルアカウントだけです。
- 対処: 接続先の WinRM で Basic 認証を有効にするか、ドメインのアカウントなら auth = "ntlm" を指定してください。

### KOYOMI-E2162 WinRM の接続先が NTLM 認証のユーザー名またはパスワードを拒否したとき

- 種類: エラー
- メッセージ: 接続先 … がユーザー名またはパスワードを受け付けません。（NTLM 認証）
- 原因: ユーザー名かパスワードが正しくない、または接続先で Negotiate 認証が有効になっていない可能性があります。
- 対処: ドメインのアカウントは on に winrm://CORP\名前@ホスト の形で指定し、接続先の WinRM で Negotiate 認証が有効であることを確認してください。

### KOYOMI-E2163 WinRM の接続先の証明書が登録された cert と一致しないとき

- 種類: エラー
- メッセージ: 接続先 … の証明書が cert と一致しません。（接続先が示した値: …）
- 原因: 接続先の証明書が入れ替えられた、または別の PC に接続している可能性があります。
- 対処: koyomi winrm cert で接続先の証明書を確認し、正しい場合は cert を書き換えてください。

### KOYOMI-E2164 WinRM の接続先との TLS 接続に失敗したとき

- 種類: エラー
- メッセージ: 接続先 … との TLS 接続に失敗しました。（…）
- 原因: 接続先の証明書または TLS の設定に問題がある可能性があります。
- 対処: 接続先の WinRM の HTTPS のリスナーの設定を確認してください。

### KOYOMI-E2165 WinRM の接続先がエラーを返したとき

- 種類: エラー
- メッセージ: 接続先 … の WinRM がエラーを返しました。（…）
- 原因: 接続先の WinRM が要求を拒否しました。
- 対処: 接続先の WinRM のログと、ユーザーの権限を確認してください。

### KOYOMI-E2170 メールボックスのサーバーに接続できないとき

- 種類: エラー
- メッセージ: ジョブネット … のメールボックス … のサーバーに接続できません。（…）
- 原因: メールサーバーのアドレスやポートが正しくない、またはネットワークに問題がある可能性があります。
- 対処: メールサーバーのアドレスとポート、ネットワークの状態を確認してください。

### KOYOMI-E2171 メールボックスのサーバーとの TLS 接続に失敗したとき

- 種類: エラー
- メッセージ: ジョブネット … のメールボックス … のサーバーとの TLS 接続に失敗しました。（…）
- 原因: メールサーバーの証明書または TLS の設定に問題がある可能性があります。
- 対処: メールサーバーのアドレスとポート、証明書の状態を確認してください。

### KOYOMI-E2172 メールボックスにログインできないとき

- 種類: エラー
- メッセージ: ジョブネット … のメールボックス … にログインできません。
- 原因: ユーザー名またはパスワードが正しくない可能性があります。
- 対処: ユーザー名を確認し、koyomi secret set … でパスワードを保存し直してください。

### KOYOMI-E2173 メールボックスのフォルダーが存在しないとき

- 種類: エラー
- メッセージ: ジョブネット … のメールボックス … のフォルダーが存在しません。
- 原因: 指定したフォルダーが、メールサーバーにありません。
- 対処: mail に指定したフォルダーの名前を確認してください。

### KOYOMI-E2174 メールボックスのパスワードのシークレットが保存されていないとき

- 種類: エラー
