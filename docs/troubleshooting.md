# こんな時はどうする

koyomi が表示するエラーと警告を、メッセージ ID ごとにまとめています。メッセージの先頭にある ID（例: KOYOMI-E2101）で検索してください。
「…」の部分には、接続先の名前などの具体的な内容が入ります。

## 設定・起動（10xx）

### KOYOMI-E1001 [groups] のグループが PC の配列で指定されていないとき

- 種類: エラー
- メッセージ: [groups] のグループ … が、PC の配列で指定されていません。
- 原因: グループには、1 台以上の PC の配列を指定する必要があるためです。
- 対処: … = ["ssh://ops@web1", "ssh://ops@web2"] のように、PC を配列で指定してください。

### KOYOMI-E1002 [groups] のグループの PC が上限を超えているとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC が … 台を超えています。
- 原因: 1 つのグループに指定できる PC の数には上限があるためです。
- 対処: PC を … 台以内にしてください。

### KOYOMI-E1003 [groups] の PC に使用できない項目が指定されているとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC に、使用できない項目 … が指定されています。
- 原因: PC を表の形式で指定するとき、使用できる項目は on、host_key、cert だけであるためです。
- 対処: … を削除してください。

### KOYOMI-E1004 [groups] の PC の項目が文字列でないとき

- 種類: エラー
- メッセージ: [groups] のグループ … の … が、文字列で指定されていません。
- 原因: PC を表の形式で指定するとき、on、host_key、cert は文字列である必要があるためです。
- 対処: … には文字列を指定してください。

### KOYOMI-E1005 [groups] の PC に on が指定されていないとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC に、on が指定されていません。
- 原因: PC を表の形式で指定するとき、PC のアドレスを on で指定する必要があるためです。
- 対処: { on = "ssh://ops@web1", host_key = "SHA256:…" } のように、on を指定してください。

### KOYOMI-E1006 [groups] の PC に { を含む値が指定されているとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC に、{…} を含む値は指定できません。（…）
- 原因: グループの PC の指定には、{ を含む値を使用できないためです。
- 対処: { を含まないアドレスを指定してください。

### KOYOMI-E1007 [groups] の PC のアドレスが ssh:// でも winrm:// でもないとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC のアドレス … が正しくありません。
- 原因: アドレスが ssh:// でも winrm:// でも始まっていないためです。
- 対処: ssh://[ユーザー@]ホスト[:ポート]、または winrm://ユーザー@ホスト[:ポート] の形式で指定してください。

### KOYOMI-E1008 [groups] の PC の指定が正しくないとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC の指定が正しくありません。（…）
- 原因: PC のアドレス、host_key、または cert の形式が正しくないためです。
- 対処: （）内の理由を確認して、PC の指定を修正してください。

### KOYOMI-E1009 [groups] の 1 つのグループに ssh:// と winrm:// の PC が混在しているとき

- 種類: エラー
- メッセージ: [groups] のグループ … に、ssh:// と winrm:// の PC が混在しています。
- 原因: 1 つのグループは、ssh と winrm のどちらか一方の接続にしか使用できないためです。
- 対処: 1 つのグループには、ssh:// または winrm:// のどちらかだけを指定してください。

### KOYOMI-E1010 [groups] の PC に、接続方式に合わない host_key または cert が指定されているとき

- 種類: エラー
- メッセージ: [groups] のグループ … の PC … に、… は指定できません。
- 原因: host_key は ssh:// の PC に、cert は winrm:// の PC にだけ指定できるためです。
- 対処: … は …:// の PC にだけ指定してください。

### KOYOMI-E1011 [groups] の 1 つのグループに同じ PC が重複しているとき

- 種類: エラー
- メッセージ: [groups] のグループ … に、同じ PC が重複して指定されています。（…）
- 原因: 同じアドレスの PC を、1 つのグループに 2 回以上指定できないためです。
- 対処: 重複している PC を削除してください。

### KOYOMI-E1012 [groups] または [vars] の名前に使用できない文字が含まれるとき

- 種類: エラー
- メッセージ: … の名前 … は使用できません。
- 原因: 名前には、英数字と _ だけを使用できるためです。
- 対処: … として読み込めるように、英数字と _ だけの名前を指定してください。

### KOYOMI-E1013 ジョブの on が、[groups] にないグループを指しているとき

- 種類: エラー
- メッセージ: グループ … が、koyomi.toml の [groups] にありません。
- 原因: on で指定したグループが、koyomi.toml の [groups] に定義されていないためです。
- 対処: [groups] に … を追加するか、on = "group:…" の名前を修正してください。

### KOYOMI-E1014 ジョブの kind と、on で指定したグループの PC の種類が一致しないとき

- 種類: エラー
- メッセージ: グループ … の PC は …:// で指定されており、ジョブの kind と一致しません。
- 原因: ssh には ssh:// の PC のグループを、winrm には winrm:// の PC のグループを指定する必要があるためです。
- 対処: kind = "…" の on には、…:// の PC のグループを指定してください。

### KOYOMI-E1015 [standby] または [primary] が、[[remote]] にない接続先を指しているとき

- 種類: エラー
- メッセージ: […] の … に指定された … は、[[remote]] の name にありません。
- 原因: 接続先の指定には、[[remote]] で定義した name を使用する必要があるためです。
- 対処: [[remote]] で定義した name を指定するか、[[remote]] を追加してください。

### KOYOMI-E1016 every を時間として読み込めないとき

- 種類: エラー
- メッセージ: […] の every を時間として読み込めません。（…）
- 原因: every が、0 より長い、数値と単位（30s、5m、1h など）の形式の時間になっていないためです。
- 対処: every には 30s、5m のように、数値と単位を指定してください。

### KOYOMI-E1017 every が指定できる範囲を外れているとき

- 種類: エラー
- メッセージ: […] の every が範囲外です。
- 原因: every に指定できる時間には、下限と上限があるためです。
- 対処: every には … から … までの時間を指定してください。

### KOYOMI-E1018 misses が指定できる範囲を外れているとき

- 種類: エラー
- メッセージ: […] の misses が範囲外です。
- 原因: misses に指定できるのは、1 から 20 までの数であるためです。
- 対処: misses には 1 から 20 までの数を指定してください。

### KOYOMI-E1019 [ping] の url が正しくないとき

- 種類: エラー
- メッセージ: [ping] の url が正しくありません。
- 原因: url が、secret:<名前> でも http:// や https:// で始まるアドレスでもないためです。
- 対処: url には、secret:<名前>、または http:// か https:// で始まるアドレスを指定してください。

### KOYOMI-E1020 [[remote]] の name が正しくないとき

- 種類: エラー
- メッセージ: [[remote]] の name が正しくありません。
- 原因: name が空、または空白を含んでいるためです。
- 対処: name には、空白を含まない名前を指定してください。

### KOYOMI-E1021 [[remote]] の url が正しくないとき

- 種類: エラー
- メッセージ: [[remote]] … の url が正しくありません。
- 原因: url が、https:// で始まる <PC>:<port> の形式になっていないためです。
- 対処: url は https://<PC>:<port> の形式で指定してください。LAN では TLS のみ使用できます。

### KOYOMI-E1022 [[remote]] の fingerprint が SHA-256 の形式でないとき

- 種類: エラー
- メッセージ: [[remote]] … の fingerprint が SHA-256 の形式ではありません。
- 原因: fingerprint が、64 桁の 16 進数になっていないためです。
- 対処: 接続先の PC で koyomi http fingerprint を実行するか、この PC で koyomi remote peek <url> を実行して、フィンガープリントを確認してください。

### KOYOMI-E1023 token が secret:<名前> の形式でないとき

- 種類: エラー
- メッセージ: … の token が、secret:<名前> の形式で指定されていません。
- 原因: token が secret:<名前> の形式でないためです。
- 対処: token には secret:<名前> を指定し、値は koyomi secret set <名前> で OS の資格情報に保存してください。

### KOYOMI-E1024 [http] の port が範囲外のとき

- 種類: エラー
- メッセージ: [http] の port が範囲外です。
- 原因: port が 0 であるためです。
- 対処: port には 1 から 65535 までの数を指定してください。

### KOYOMI-E1025 [http] の tailnet が正しくないとき

- 種類: エラー
- メッセージ: [http] の tailnet が正しくありません。
- 原因: tailnet が 0、または port と同じ値であるためです。
- 対処: tailnet には、port とは別の 1 から 65535 までのポートを指定してください。

### KOYOMI-E1026 [http] に tailnet があり、tailscale で接続する利用者がいないとき

- 種類: エラー
- メッセージ: [http] に tailnet が指定されていますが、tailscale で接続する利用者がいません。
- 原因: [[http.user]] に、tailscale が指定された利用者が 1 人もいないためです。
- 対処: [[http.user]] に tailscale = "<ログイン名>" を指定してください。

### KOYOMI-E1027 [[http.user]] の name が正しくないとき

- 種類: エラー
- メッセージ: [[http.user]] の name が正しくありません。
- 原因: name が、空、空白を含む、または default であるためです。
- 対処: name には、空白を含まず default 以外の名前を指定してください。

### KOYOMI-E1028 [[remote]] の name、[[http.user]] の name または tailscale が重複しているとき

- 種類: エラー
- メッセージ: … の … … が重複しています。
- 原因: 同じ値を持つ項目が 2 つ以上あるためです。
- 対処: … が重複しないように指定してください。

### KOYOMI-E1029 [[http.user]] の role、nets、roles が正しくないとき

- 種類: エラー
- メッセージ: [[http.user]] … の設定が正しくありません。（…）
- 原因: role、nets、roles のいずれかの指定が正しくないためです。
- 対処: role、nets、roles の指定を確認してください。

### KOYOMI-E1030 role = "admin" の利用者に nets または roles が指定されているとき

- 種類: エラー
- メッセージ: [[http.user]] … は role = "admin" ですが、nets と roles も指定されています。
- 原因: admin はすべてのジョブネットに適用されるため、nets や roles で対象を絞れないためです。
- 対処: nets と roles を削除してください。

### KOYOMI-E1031 [[http.user]] の tailscale が正しくないとき

- 種類: エラー
- メッセージ: [[http.user]] … の tailscale が正しくありません。（…）
- 原因: tailscale が、ログイン名でもタグでもない形式で指定されているためです。
- 対処: tailscale には、Tailscale のログイン名（sato@example.com）またはタグ（tag:koyomi-ha）を指定してください。

### KOYOMI-E1032 [[http.user]] に tailscale があり、[http] に tailnet がないとき

- 種類: エラー
- メッセージ: [[http.user]] … に tailscale が指定されていますが、[http] に tailnet がありません。
- 原因: tailscale での接続は、tailnet で待ち受けるポートを通るためです。
- 対処: [http] の tailnet に、待ち受けるポートを指定してください。

### KOYOMI-E1033 koyomi.toml に未知の項目が指定されているとき

- 種類: エラー
- メッセージ: … に、未知の項目 … があります。
- 原因: このバージョンが認識しない項目が、指定されているためです。
- 対処: 項目名を確認して修正するか、削除してください。

### KOYOMI-E1034 koyomi.toml に必須の項目がないとき

- 種類: エラー
- メッセージ: … に、必須の項目 … がありません。
- 原因: 必要な項目が、指定されていないためです。
- 対処: … を追加してください。

### KOYOMI-E1035 koyomi.toml の値が、指定できる値のどれでもないとき

- 種類: エラー
- メッセージ: … の値 … は使用できません。（指定できる値は … です）
- 原因: 値が、指定できる値のどれでもないためです。
- 対処: 指定できる値のいずれかを指定してください。

### KOYOMI-E1036 koyomi.toml の値の型や範囲、書式が正しくないとき

- 種類: エラー
- メッセージ: … を読み込めません。（…）
- 原因: 値の型または範囲が正しくない、あるいは TOML の書式に誤りがあるためです。
- 対処: 項目の名前と値を確認して、koyomi.toml を修正してください。

### KOYOMI-E1037 concurrency、keep_days、log_max_mb に 0 が指定されているとき

- 種類: エラー
- メッセージ: … に 0 が指定されています。
- 原因: concurrency、keep_days、log_max_mb には、1 以上の数が必要なためです。
- 対処: … には 1 以上の数を指定してください。

### KOYOMI-E1038 [standby] と [primary] が同時に指定されているとき

- 種類: エラー
- メッセージ: [standby] と [primary] が同時に指定されています。
- 原因: 1 つの PC が、待機系と、待機系に監視される側の両方にはなれないためです。
- 対処: 待機系の PC には [standby] を、監視される側の PC には [primary] を指定し、どちらか一方を削除してください。

### KOYOMI-E1039 [locks] の名前がロック名として使用できないとき

- 種類: エラー
- メッセージ: [locks] の … が、ロック名として使用できません。
- 原因: ロック名には、/ \ : などの文字を使用できないためです。
- 対処: ジョブネットの lock と同じ規則で、使用できる文字だけの名前を指定してください。

### KOYOMI-E1040 [locks] の同時に持てる数が正しくないとき

- 種類: エラー
- メッセージ: [locks] の … の数が正しくありません。
- 原因: 同時に持てる数には、1 以上の整数が必要なためです。
- 対処: "API枠" = 3 のように、1 以上の整数を指定してください。

### KOYOMI-E1041 work_dir が定義のあるフォルダーでも絶対パスでもないとき

- 種類: エラー
- メッセージ: work_dir の値 … が正しくありません。
- 原因: work_dir が、定義のあるフォルダーを表す値でも、絶対パスでもないためです。
- 対処: work_dir = '…' のように、"…"（定義のあるフォルダー）か絶対パスを指定してください。

### KOYOMI-E1042 [vars] の値が文字列でないとき

- 種類: エラー
- メッセージ: [vars] の … が、文字列で指定されていません。
- 原因: [vars] の値には、文字列が必要なためです。
- 対処: … = '\\nas\backup' のように、文字列を指定してください。

### KOYOMI-E1043 [vars] の値に {param:…} または {var:…} が含まれているとき

- 種類: エラー
- メッセージ: [vars] の … に、{param:…} または {var:…} が含まれています。
- 原因: [vars] の値には、ジョブネットの値や別の [vars] を参照する記述を含められないためです。
- 対処: {param:…} と {var:…} を削除してください。{date} などは使用できます。

### KOYOMI-E1044 [vars] の値の日付の書式が正しくないとき

- 種類: エラー
- メッセージ: [vars] の … の値が正しくありません。（…）
- 原因: {date} などの置き換えの書式が、正しくないためです。
- 対処: （）内の理由を確認して、値を修正してください。

## 接続・認証（21xx）

### KOYOMI-E2101 接続先のエンジンに接続できないとき

- 種類: エラー
- メッセージ: 接続先 … に接続できません。（…）
- 原因: 接続先のエンジンが停止している、HTTP を受け付ける設定になっていない、またはファイアウォールで通信が遮断されている可能性があります。
- 対処: 接続先のエンジンが起動していること、[http] の lan = true、ファイアウォールの設定を確認してください。

### KOYOMI-E2102 要求が届いたかどうかを確認できないとき

- 種類: エラー
- メッセージ: 要求が接続先に届いたかどうかを確認できません。（…）
- 原因: 要求の送信後に通信が切断された、または応答の内容を確認できなかったため、接続先で処理された可能性があります。
- 対処: 履歴を確認し、必要な場合は再度実行してください。

### KOYOMI-E2103 接続先の証明書が登録された fingerprint と一致しないとき

- 種類: エラー
- メッセージ: 接続先 … の証明書が登録された fingerprint と一致しません。（接続先が示した値: …）
- 原因: 接続先の証明書が入れ替えられた、または別の PC に接続している可能性があります。
- 対処: 接続先で koyomi http fingerprint を実行して値を比較し、一致する場合は koyomi.toml の fingerprint を書き換えてください。

### KOYOMI-E2104 接続先からの応答がタイムアウトしたとき

- 種類: エラー
- メッセージ: 接続先 … からの応答がタイムアウトしました。
- 原因: 通信が遅い、または接続先のエンジンが混み合っている可能性があります。
- 対処: 通信の状態と接続先の負荷を確認し、再度実行してください。

### KOYOMI-E2105 接続先のトークンのシークレットが保存されていないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンを保存したシークレット … が存在しません。
- 原因: 資格情報ストアに、接続先の [[remote]] の token が指すシークレットが保存されていません。
- 対処: koyomi secret set … を実行し、接続先の [http] のトークンを保存してください。

### KOYOMI-E2106 接続先のトークンのシークレットを資格情報ストアから読み込めないとき

- 種類: エラー
- メッセージ: 接続先 … のトークンのシークレット … を読み込めません。（…）
- 原因: 資格情報ストアにアクセスできない、またはストアがシークレットの読み込みを拒否した可能性があります。
- 対処: 資格情報ストアの状態を確認し、koyomi secret set … でトークンを保存し直してください。

### KOYOMI-E2107 接続先がトークンを受け付けないとき

- 種類: エラー
- メッセージ: 接続先 … がトークンを受け付けません。
- 原因: 保存されたトークンが、接続先の [http] に登録されたトークンと一致しない可能性があります。
- 対処: 接続先の [http] のトークンを確認し、koyomi secret set … で保存し直してください。

### KOYOMI-E2108 画面とエンジンの通信形式のバージョンが一致しないとき

- 種類: エラー
- メッセージ: 画面とエンジンのバージョンが一致しません。（画面 …、エンジン …）
- 原因: 画面が送った通信形式の番号が、接続先のエンジンのものと異なります。
- 対処: 画面とエンジンの koyomi を同じバージョンに更新してください。

### KOYOMI-E2109 接続先の応答を読み込めないとき

### KOYOMI-E2201 操作に必要なロールが不足しているとき

- 種類: エラー
- メッセージ: 利用者 … は、[[http.user]] に登録されていません。

- 対処: 接続先の管理者に、[[http.user]] への登録を依頼してください。

- メッセージ: 値 … を渡せません。このジョブネットには [params] がありません。
- 原因: 渡された値の名前が、ジョブネットの [params] に定義されていないためです。
- 対処: ジョブネットに [params] を定義するか、値の指定を取り消してください。

### KOYOMI-E3479 [params] にない名前の値が渡されたとき

- 種類: エラー
- メッセージ: 値 … は、[params] にありません。（定義されているのは …）
- 原因: 渡された値の名前が、ジョブネットの [params] に定義されていないためです。
- 対処: [params] にある名前を指定してください。

### KOYOMI-E3480 日付の置き換えに、移動する数がないとき

- 種類: エラー
- メッセージ: … の、移動する数が指定されていません。
- 原因: + または - の後に、数が続いていないためです。
- 対処: {date-1d} のように、+ または - の後に数と単位を指定してください。

### KOYOMI-E3481 日付の置き換えに、単位がないとき

- 種類: エラー
- メッセージ: … に、単位が指定されていません。
- 原因: {date…} の移動には、単位が必要なためです。
- 対処: 単位には、d、bd、m、y のいずれかを指定してください。

### KOYOMI-E3482 日付の置き換えの単位を読み込めないとき

- 種類: エラー
- メッセージ: … の単位 … を読み込めません。
- 原因: 使用できない単位が、指定されているためです。
- 対処: {month} には数のみ、または m を、{date} には d、bd、m、y を指定してください。

### KOYOMI-E3483 日付の置き換えの書式を読み込めないとき

- 種類: エラー
- メッセージ: … の書式 … を読み込めません。
- 原因: 日付の書式が、空であるか、正しくないためです。
- 対処: {date:%Y%m%d} のように、日付の書式を指定してください。

### KOYOMI-E3484 ジョブの項目の置き換えに失敗したとき

- 種類: エラー
- メッセージ: ジョブ … の … を展開できません。（…）
- 原因: {param:…}、{var:…}、{date…} などの置き換えに失敗したためです。
- 対処: （）内の理由を確認して、{param:…}、{var:…}、{date…} の指定を修正してください。

## カレンダー（41xx）

### KOYOMI-E4101 同じ名前のカレンダーがすでにあるとき

- 種類: エラー
- メッセージ: カレンダー … はすでに存在します。
- 原因: 指定した名前のカレンダーがすでに登録されています。
- 対処: 別の名前を指定してください。

### KOYOMI-E4102 名前を指定せずにカレンダーを作成または操作しようとしたとき

- 種類: エラー
- メッセージ: カレンダーの名前が指定されていません。
- 原因: カレンダーの操作には名前が必要です。
- 対処: 名前を入力してください。

### KOYOMI-E4103 カレンダーの名前に使用できない文字を指定したとき

- 種類: エラー
- メッセージ: カレンダーの名前 … に、使用できない文字が含まれています。
- 原因: ファイル名として使用できない文字が含まれているためです。
- 対処: / \ : * ? " < > | を含まず、末尾が . ではない名前を指定してください。

### KOYOMI-E4104 存在しないカレンダーを指定したとき

- 種類: エラー
- メッセージ: カレンダー … は存在しません。
- 原因: calendars フォルダーに、指定した名前のファイルがないためです。
- 対処: 名前を確認するか、カレンダーを作成してください。

### KOYOMI-E4105 カレンダーが、読み込んだあとにほかの場所で変更または削除されていたとき

- 種類: エラー
- メッセージ: カレンダー … は、ほかの場所で変更されています。
- 原因: カレンダーのファイルの内容が、読み込んだときの内容と一致しないためです。
- 対処: 最新の内容を読み込み直してから、再度実行してください。

### KOYOMI-E4106 カレンダーに未知の項目が書かれているとき

- 種類: エラー
- メッセージ: カレンダー … に、未知の項目 … があります。
- 原因: カレンダーのファイルに、このバージョンが認識しない項目が書かれているためです。
- 対処: 項目名を確認して修正してください。

### KOYOMI-E4107 カレンダーのファイルが TOML として読み込めないとき

- 種類: エラー
- メッセージ: カレンダー … の記述が TOML の書式に一致しません。（…）

- 対処: ファイルの記述を修正してください。

### KOYOMI-E4108 カレンダーに format の指定がないとき

- 対処: ファイルの先頭に format = 1 を追加してください。

### KOYOMI-E4109 カレンダーの format が、このバージョンで読み込めない値のとき
