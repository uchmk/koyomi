# README の画像の置き場

README の「What it looks like」と、紹介画像（GitHub の Social preview）の右に入れる実画面の置き場。
どれも 0.37.0 のビルドを既定のテーマで撮った。持ち主の設定と状態は使わず、撮るためだけに作った箱
（設定・状態・名前付きパイプ・通知の出し先が、すべてその箱だけのもの）のエンジンに、
デモのジョブネット 7 本（夜間バックアップ・売上レポート・在庫の同期・死活監視・ログの掃除・日報の作成・月次締め）と、
3 日分の履歴とログを読ませてつないだ。今日の売上レポートは、集計のジョブが終了コード 2 で失敗している。

| ファイル | 何を写すか | 撮り方 |
| --- | --- | --- |
| `today.png` | 今日。失敗した売上レポートの行を選んだところ。今日の実行と予定の表、ガントチャート、右に選んだジョブネットの次の予定と構成 | `scripts/keys.ps1` で窓を `<Size:1600x1000>` にして `<Shot:…>` で撮り（150 % なので 2400x1500）、1600x1000 に縮める |
| `history.png` | 履歴。失敗した売上レポートの実行を選んだところ。ジョブの流れ・状態・終了コードと、失敗したジョブのログ | today.png と同じ |
| `koyomi.gif` | 今日 → 失敗した実行を選ぶ → 月次締めのジョブネットの流れ → 会社のカレンダー → 履歴で失敗したジョブのログ → 対応済みにする。操作を右下に字幕で出す | 各画面を today.png と同じく撮り、1200x750 に縮めて字幕を重ね、ffmpeg で 1 枚 2.5〜3 秒・10 fps・128 色の GIF にする（約 15 秒、くり返す） |
| `banner-shot.png` | `docs/banner.html` の右の実画面。今日（行を選ばない） | today.png と同じ |

撮るときの注意:

- **持ち主の設定と状態を使わない。**`KOYOMI_CONFIG_HOME`・`KOYOMI_STATE_HOME`・`UCHMK_CONFIG_DIR` を箱の中に向け、
  `KOYOMI_ADDRESS` を箱だけの名前付きパイプにし、通知は `ITO_NOTIFY_SINK` でファイルに出す。持ち主のエンジンとサービスには触らない。
- デモのジョブネットのコマンド（`D:\ops\…`）は架空のもの。今日の予定の残り（23:30 の日報の作成）が来る前に、箱のエンジンを止める。
- **全部のコマを見て、利用者の名前・ホストの名前・IP アドレス・token が写っていないことを確かめる。**接続先は「この PC」だけにする。
- クリックのあとは、タイトルバーの空いたところを指す（`<Hover:0.3,0.015>`）。指したままだとツールチップや行の色が写る。
- 紹介画像は `docs/social-preview.png`（元は `docs/banner.html`。描き直し方は HTML の冒頭）。
  GitHub に API が無いので、Settings > General > Social preview から手で上げる。
